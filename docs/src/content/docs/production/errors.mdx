Every failure raised by the SDK is a `PoliPage::Error` subclass. Catch a specific subclass when you want narrow control (`rescue PoliPage::RateLimitError`), or `rescue PoliPage::Error` to handle every SDK failure at once. The `code:` reader is the machine-readable string; `request_id:` is what to quote on a support ticket.

## The error hierarchy

```ruby
require "poli_page"

client = PoliPage::Client.new(api_key: ENV.fetch("POLI_PAGE_API_KEY"))

begin
  client.render.pdf(project: "billing", template: "invoice", data: {})
rescue PoliPage::Error => e
  warn "#{e.class}: #{e.code} (request_id=#{e.request_id})"
end
```

HTTP status maps to a subclass via `PoliPage::Internal::HTTP.classify`:

- `400` → `ValidationError`
- `401` → `AuthenticationError`
- `403` → `PermissionDeniedError`
- `404` → `NotFoundError`
- `410` → `GoneError`
- `429` → `RateLimitError`
- other 4xx / 5xx → `APIError`

The SDK-internal subclasses (`InvalidOptionsError`, `ConnectionError`, `TimeoutError`, `DownloadError`, `InternalError`) are raised before any HTTP call or in response to a network-layer failure.

## Predicate helpers

`PoliPage::Error` exposes `#auth_error?` (`status` 401 or 403), `#rate_limit_error?` (429), `#validation_error?` (400), `#network_error?` (`code` `network_error` or `timeout`), and `#retryable?` for callers who want a single rescue clause backed by introspection. They read `status` and `code`, not the class, so a `DownloadError` with a storage 403 is an `auth_error?`. `#retryable?` is true for a network error, a timeout, a 5xx or a 429, except `QUOTA_EXCEEDED`, `OVERAGE_CAP_EXCEEDED`, `STORAGE_ACCESS_DENIED` and `DOWNLOAD_FAILED`.

The SDK's own messages are fixed texts: `Network request failed`, `Request timed out after <ms>ms`, `Failed to download PDF: HTTP <status>` or `Failed to download PDF: network error`, `apiKey is required`, `project is required`, and `HTTP <status>` for an error answer whose body is not JSON. For a network error, a timeout or a failed download, `#cause` is the HTTP library's exception.

## Example

```ruby
require "poli_page"

client = PoliPage::Client.new(api_key: ENV.fetch("POLI_PAGE_API_KEY"))

begin
  pdf = client.render.pdf(
    project:  "billing",
    template: "invoice",
    data:     { invoiceNumber: "INV-001" }
  )
rescue PoliPage::RateLimitError => e
  # Custom strategy beyond the SDK's built-in retries.
  warn "rate limited (request_id=#{e.request_id}); backing off"
rescue PoliPage::Error => e
  warn "render failed: #{e.code} (#{e.class})"
  raise
end
```
